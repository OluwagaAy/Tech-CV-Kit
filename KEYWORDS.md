# 🔑 Keyword Bank

Recruiters and applicant tracking systems search CVs for **exact words**. Only use a keyword if you can talk about it in an interview.

How to use this: open the job ad, highlight every tool and term, then check which ones below you can honestly claim. Put those in your Skills section **and** in your bullet points.

---

## 🛡️ SOC Analyst / Security Operations

**Tools:** Splunk, Microsoft Sentinel, IBM QRadar, Elastic (ELK), Wazuh, Microsoft Defender for Endpoint, CrowdStrike Falcon, Wireshark, Zeek, Suricata, Snort
**Terms:** SIEM, EDR, XDR, alert triage, incident response, threat hunting, log analysis, IOCs, MITRE ATT&CK, playbooks, escalation, false positives, phishing analysis
**Certs they ask for:** CompTIA Security+, CySA+, ISC2 CC, Splunk Core Certified User, Microsoft SC-200

## 🖥️ IT Support / Service Desk

**Tools:** Microsoft 365, Active Directory, Entra ID (Azure AD), Intune, Google Workspace, ServiceNow, Jira Service Management, TeamViewer, AnyDesk
**Terms:** first-line / second-line support, ticketing, SLA, troubleshooting, user provisioning, password resets, LAN/WAN, DNS, DHCP, printers, backups, onboarding
**Certs they ask for:** CompTIA A+, Network+, ITIL 4 Foundation, Microsoft MD-102, Google IT Support

## ☁️ Cloud (Azure / AWS)

**Tools:** Azure portal, AWS Console, Terraform, Azure DevOps, GitHub Actions, Docker, Kubernetes, PowerShell, Azure CLI
**Terms:** IaaS, PaaS, virtual networks, IAM, RBAC, cost optimisation, high availability, backup and disaster recovery, infrastructure as code, monitoring
**Certs they ask for:** AZ-900, AZ-104, AZ-500, AWS Cloud Practitioner, AWS Solutions Architect Associate

## 📋 GRC (Governance, Risk & Compliance)

**Tools:** Excel risk registers, GRC platforms (ServiceNow GRC, Archer), policy management tools
**Terms:** risk assessment, risk register, controls testing, internal audit, ISO 27001, NIST CSF, NDPA (Nigeria Data Protection Act), CBN cybersecurity framework, PCI DSS, business continuity, vendor risk, policies and procedures
**Certs they ask for:** ISO 27001 Lead Implementer / Lead Auditor, CISA, CRISC, CISM, CGEIT

## 🎯 Penetration Testing / Offensive Security

**Tools:** Kali Linux, Nmap, Burp Suite, Metasploit, Nessus, OpenVAS, Nikto, Gobuster, Hydra, John the Ripper, BloodHound
**Terms:** vulnerability assessment, penetration testing, OWASP Top 10, web application testing, network testing, privilege escalation, reporting, remediation, CVSS
**Certs they ask for:** CEH, CompTIA PenTest+, eJPT, OSCP
