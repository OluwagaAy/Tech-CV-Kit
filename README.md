# 📄 Tech CV Kit

**Everything you need to turn your skills into interviews.** CV templates, a role-by-role keyword bank and ready-to-use application emails for IT and cybersecurity beginners in Nigeria.

By **Coach AY** (Ayomide Oluwaga). I review CVs for my mentees every week, and the same mistakes keep costing good people interviews. This kit fixes them.

## 📂 What's inside

| File | What it's for |
|---|---|
| [CV-TEMPLATE.md](CV-TEMPLATE.md) | A 1 to 2 page CV template, with a version for people with **no experience yet** |
| [KEYWORDS.md](KEYWORDS.md) | The exact tools and terms employers search for, by role: SOC, IT support, cloud, GRC, pentesting |
| [EMAIL-TEMPLATES.md](EMAIL-TEMPLATES.md) | Application email, follow-up, and thank-you-after-interview templates |

## ⚡ The 7 rules

1. **1 to 2 pages.** Nobody reads page 4.
2. **Skills, tools and certs at the top**, not buried at the end.
3. **Mirror the job ad.** If they say Nessus and you have used it, write Nessus, not "vulnerability scanners".
4. **Numbers beat duties.** "Resolved 30+ tickets a week" beats "provided IT support".
5. **No experience? Show proof.** A Projects / Home Lab section counts. Start with my [Cyber-Home-Lab-Starter](https://github.com/OluwagaAy/Cyber-Home-Lab-Starter).
6. **Save as PDF** named `Firstname-Lastname-CV.pdf`.
7. **Apply within 48 hours** of a posting. Early applications get seen first.
